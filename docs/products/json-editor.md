# 开源 JSON 编辑器（json-editor）

## 简介

提供 JSON 与 JSON Schema 的可视化编辑能力，内置 **JSONEditor**、**SchemaEditor**，可通过表单可视化化界面维护 schema 和 json 数据，可用于支持组件与页面的配置可视化。

## 核心能力

1. [SchemaEditor](https://github.com/wibetter/json-editor/tree/master/packages/json-editor): 以表单的形式编辑 schema 数据，可用于在线设计组件的配置面板;
2. [JSONEditor](https://github.com/wibetter/json-editor/tree/master/packages/json-schema-editor): 以表单的形式编辑 json 数据，可用于充当组件的配置面板;
3. [JSONUtils](https://github.com/wibetter/json-editor/tree/master/packages/json-utils): 提供JSON相关的各类工具方法，比如schema转json、json转schema、json元数据分析等。
