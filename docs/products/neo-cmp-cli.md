# 自定义组件开发工具

## 简介

企业级商业化产品，含 CLI、事件动作机制、平台实体数据源、模块共享、组件运行时上下文等使用说明。

## 核心能力

- **CLI**：提供自定义组件模板、调试、授权登录、发布等功能命令
- **事件动作机制**：通过事件动作实现组件之间数据联动和交互响应
- **平台实体数据源**：可在组件中访问平台实体数据源
- **模块共享**：组件间通过模块联邦方式进行模块共享
- **组件运行时上下文**：提供组件运行时上下文能力
