# 小猪新闻（H5版，pigNews）

## 简介

滚动资讯、高清图集、视频集锦的 H5 新闻应用。

## 核心能力

- **滚动资讯**：实时滚动的最新资讯
- **高清图集**：高清图片合集展示
- **视频集锦**：视频内容集成展示
