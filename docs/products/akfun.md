# 前端脚手架（akfun）

## 简介

前端通用脚手架：基于 Webpack 与 Rollup 的多场景前端打包工具，零配置、开箱即用。

## 核心特性

- **多场景打包**：基于 Webpack 与 Rollup，覆盖多种前端场景
- **零配置**：无需繁琐配置即可开始使用
- **开箱即用**：内置常用能力，快速启动项目
